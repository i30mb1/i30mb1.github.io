Политика конфиденциальности

Последнее обновление: 26 июля 2026

1. Введение

Bondcast — приложение для Android, которое стримит видео и звук с камеры телефона на сервер по вашему выбору: собственный сервер Bondcast Stream, любой другой SRT-сервер или напрямую в Twitch. Эту политику ведёт разработчик приложения (i30mb1).

2. Главное коротко

У Bondcast нет собственного облака, и разработчик не собирает данные на своих серверах. Видео и звук с камеры и микрофона идут напрямую туда, куда вы указали в настройках, — минуя разработчика. В приложении нет рекламы, аналитики и трекеров.

3. Разрешения, которые запрашивает приложение

  • Камера, микрофон — захват видео и звука для стрима.
  • Состояние сети / изменение сети — чтобы вести стрим одновременно по Wi-Fi и мобильному интернету (бондинг) и переключаться на рабочий канал при обрыве другого.
  • Foreground-сервис, уведомления, Wake Lock — чтобы стрим не останавливался при выключенном экране или свёрнутом приложении.
  • USB — опционально, для подключения внешней USB-камеры.

Ни одно из этих разрешений не используется для сбора данных о вас — только для работы самого стрима.

4. Куда уходит стрим

Адрес сервера вы указываете сами — вручную или сканированием QR-кода со своей панели Bondcast Stream. Видео и аудио идут по протоколу SRT/SRTLA (или RTMP при прямом эфире в Twitch) напрямую по этому адресу. Сервера, через который проходил бы или на котором сохранялся бы ваш стрим, у разработчика нет.

5. Вход через Twitch (опционально)

Чат поверх камеры, список зрителей чата и автоподстановка ключа трансляции работают только если вы сами включите вход через Twitch. Вход идёт по Device Code Flow — приложение никогда не видит ваш пароль от Twitch. Запрашиваемые права (scopes):

  • user:read:chat — чтение чата вашего канала;
  • moderator:read:chatters — список тех, кто сейчас в чате;
  • channel:read:stream_key — чтобы одной кнопкой подставить ключ трансляции для прямого эфира в Twitch.

Access- и refresh-токен хранятся на телефоне в зашифрованном виде (AES/GCM, ключ — в Android Keystore) и никуда не передаются, кроме самого Twitch. Сообщения чата и список зрителей запрашиваются у Twitch «вживую» для отображения поверх камеры — приложение их не сохраняет и не передаёт куда-либо ещё. Отозвать доступ можно в любой момент — выходом в настройках приложения или в настройках приложений Twitch.

6. Локальные настройки

Настройки приложения (адрес сервера, битрейт, включённые функции и т.д.) хранятся локально на телефоне и никуда не отправляются.

7. Сторонние сервисы

Приложение не использует рекламные сети, аналитику или сервисы сбора крашей. Единственный сторонний сервис, с которым оно может обмениваться данными, — Twitch, и только если вы сами включили вход через Twitch. Политика конфиденциальности Twitch: twitch.tv/p/legal/privacy-notice.

8. Безопасность

Токен Twitch хранится зашифрованным на устройстве. Соединение со стриминг-сервером можно защитить паролем (SRT passphrase) — тогда подключиться к нему сможет только тот, кто его знает.

9. Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные от них осознанно.

10. Изменения в этой политике

При изменении политики дата «Последнее обновление» вверху страницы будет обновлена соответствующим образом.
